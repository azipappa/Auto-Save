# Changelog

このプロジェクトの主な変更内容を記録します。

## [1.0.1]

### Changed

- Auto Saveウィンドウの最大高さを`600px`へ拡張

## [1.0.0]

初回リリース。

### Added

- アクティブな Scene の変更を検知する自動保存機能を追加
- 自動保存の ON / OFF 設定を追加
- `10秒`、`30秒`、`60秒` の保存待機時間を追加
- ミリ秒単位で指定できるカスタム待機時間を追加
- 再生中、コンパイル中、アセット更新中の自動保存を抑止する安全制御を追加
- Unity Editor のメニュー `Tools > Azipa Tools > Auto Save` に設定ウィンドウを追加
- `EditorPrefs` による設定の永続化を追加
- VPM パッケージ `com.azipaworks.auto-save` として配布できる構成を追加
